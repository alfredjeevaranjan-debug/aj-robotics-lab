
# Arduino LED Project

## Objective
Learn digital outputs using an Arduino-compatible board.

## Components
- Arduino-compatible board
- LED
- Suitable current-limiting resistor
- Breadboard
- Jumper wires

## Development
Document the circuit, source code, board model and test results.

## Safety
Disconnect power before changing wiring.
Check component ratings.
Never connect an LED without a suitable current-limiting resistor.
