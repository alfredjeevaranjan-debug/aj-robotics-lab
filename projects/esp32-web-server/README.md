
# ESP32 Web Server

## Objective
Explore how an ESP32 can host a simple web page on a local network.

## Components
- ESP32 development board
- USB data cable
- Computer
- Authorised local Wi-Fi network

## Development
Record the board model, framework, libraries and code.

## Security
Never publish Wi-Fi passwords, API keys or private network credentials.
Only test on networks you own or are authorised to use.
