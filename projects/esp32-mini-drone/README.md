
# ESP32 Mini Drone Concept

## Objective
Study servo control, sensors and embedded systems through simulation.

## Research
- ESP32 board specifications
- Servo motor specifications
- Power supply requirements
- Control logic
- Simulation and testing

## Development
Document the simulator, circuit design, source code and test results.

## Safety
This is a learning and simulation project, not a verified flight controller.
Do not attach propellers during initial electronics testing.
Never power servos directly from GPIO pins.
Follow applicable UK aviation rules before any physical flight.
