
# Safety Guidelines

1. Read component datasheets before use.
2. Check voltage and current ratings.
3. Disconnect power before changing circuits.
4. Use appropriate resistors and motor drivers.
5. Never power motors directly from GPIO pins.
6. Use suitable battery protection.
7. Keep liquids away from electronics.
8. Do not experiment with mains electricity unless qualified.
9. Simulate projects before physical testing where possible.
10. Stop if components overheat, swell, smoke or smell unusual.
