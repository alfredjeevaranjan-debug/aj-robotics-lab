
# Contribution Guidelines

Contributions should support safe and accurate technology education.

## Before submitting
- Explain the project's objective.
- Include component details.
- Provide circuit diagrams where relevant.
- Include tested code where possible.
- Document limitations and safety risks.
- Cite external references.
- Do not include passwords or private information.

1. Overview
2. Components
3. Circuit design
4. Code
5. Instructions
6. Testing
7. Results
